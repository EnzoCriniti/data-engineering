# Documentação do projeto

Esta pasta guarda tudo que **não é conteúdo de capítulo**: o plano de implementação, os padrões do repositório, o contrato de deploy no NAS, as decisões tomadas e o diário de cada etapa.

Os capítulos (`00-…` a `17-…`) explicam a plataforma de dados da NuvemStore. Esta pasta explica **como o próprio projeto está sendo construído**, porque essa construção também é parte da história contada no portfólio.

| Documento | Para que serve |
|---|---|
| [indice-tecnico.md](./indice-tecnico.md) | Os 18 capítulos agrupados nas cinco fases do case, com status e critérios de passagem |
| [plano-de-implementacao.md](./plano-de-implementacao.md) | As etapas, o que entra em cada uma, o que roda no NAS e quando uma etapa está pronta |
| [padrao-do-repositorio.md](./padrao-do-repositorio.md) | Estrutura de um capítulo, papel de cada arquivo, convenções de código, compose, branches e status |
| [deploy-nas-agent-platform.md](./deploy-nas-agent-platform.md) | Como o ambiente vivo é publicado no NAS pelo agent-platform e o que a plataforma precisa oferecer |
| [trilha-sem-solucoes.md](./trilha-sem-solucoes.md) | A edição de exercícios (sem gabarito), para aulas e estudo |
| [portfolio-site.md](./portfolio-site.md) | Como cada etapa vira texto no site portfólio |
| [decisoes/](./decisoes/) | Registros de decisão (um arquivo por decisão, numerados) |

# Solução — Cap. 01: Modelagem dimensional

> Gabarito de design. Siga o [GUIDE.md](./GUIDE.md) para o porquê de cada decisão. Este capítulo não tem código executável — apenas o DDL do star schema e o mapeamento OLTP→dimensional.

## DDL do Star Schema

```sql
-- dim_tempo
CREATE TABLE IF NOT EXISTS analytics.dim_tempo (
    sk_tempo   INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    data       DATE    NOT NULL UNIQUE,
    dia        INTEGER NOT NULL,
    mes        INTEGER NOT NULL,
    trimestre  INTEGER NOT NULL,
    ano        INTEGER NOT NULL
);

-- dim_cliente (SCD Type 2)
CREATE TABLE IF NOT EXISTS analytics.dim_cliente (
    sk_cliente  INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    cliente_id  INTEGER      NOT NULL,   -- natural key
    nome        VARCHAR(100) NOT NULL,
    cidade      VARCHAR(100) NOT NULL,
    email       VARCHAR(150) NOT NULL,
    valido_de   DATE         NOT NULL DEFAULT CURRENT_DATE,
    valido_ate  DATE,                     -- NULL = versão atual
    atual       BOOLEAN      NOT NULL DEFAULT true
);

-- dim_produto (categoria denormalizada)
CREATE TABLE IF NOT EXISTS analytics.dim_produto (
    sk_produto  INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    produto_id  INTEGER      NOT NULL,   -- natural key
    nome        VARCHAR(120) NOT NULL,
    categoria   VARCHAR(80)  NOT NULL     -- denormalizado de categoria.nome
);

-- fct_vendas (grão: um item vendido em um pedido)
CREATE TABLE IF NOT EXISTS analytics.fct_vendas (
    sk_venda       INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sk_tempo        INTEGER NOT NULL REFERENCES analytics.dim_tempo(sk_tempo),
    sk_cliente      INTEGER NOT NULL REFERENCES analytics.dim_cliente(sk_cliente),
    sk_produto      INTEGER NOT NULL REFERENCES analytics.dim_produto(sk_produto),
    pedido_id       INTEGER NOT NULL,     -- rastreabilidade
    item_pedido_id  INTEGER NOT NULL,     -- rastreabilidade
    quantidade      INTEGER       NOT NULL,
    valor_total     NUMERIC(12,2) NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_fct_vendas_tempo    ON analytics.fct_vendas(sk_tempo);
CREATE INDEX IF NOT EXISTS idx_fct_vendas_cliente  ON analytics.fct_vendas(sk_cliente);
CREATE INDEX IF NOT EXISTS idx_fct_vendas_produto  ON analytics.fct_vendas(sk_produto);
```

## Mapeamento OLTP → Dimensional

| Origem (OLTP) | Destino | Transformação |
|---|---|---|
| `pedido.data_pedido` | `dim_tempo(data, dia, mes, trimestre, ano)` | EXTRACT de DATE |
| `cliente(nome, cidade, email)` | `dim_cliente` + SCD2 cols | Adicionar sk, valido_de/ate, atual |
| `produto.nome` + `categoria.nome` | `dim_produto(nome, categoria)` | JOIN e denormalização |
| `item_pedido(quantidade, preco_unitario)` | `fct_vendas(quantidade, valor_total)` | valor_total = quantidade × preco_unitario |
| `pedido.status` | filtro na fato | Excluir `status = 'cancelado'` |

## Regras de negócio documentadas

1. **Grão**: um item vendido em um pedido (1 linha = 1 `item_pedido`).
2. **Pedidos cancelados**: excluídos da fato — não geram receita.
3. **SCD2 em dim_cliente**: cidade muda → fechar versão atual, abrir nova.
4. **Denormalização**: `dim_produto.categoria` embute o nome da categoria.
